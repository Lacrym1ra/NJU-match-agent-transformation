## 不可替代约束

- Agent 类型必须与主开发 Agent 不同；
- 不导入本项目历史会话、memory、聊天摘要或口头背景；
- 初始输入只包含仓库、`SPEC.md` 和 `PLAN.md`；
- 选择 1–2 个尚未由该 Agent 接触的细粒度 Task；
- 遇到歧义必须暂停提问，禁止学生在执行中补充隐含设计；
- 保存原始 prompt、提问、耗时、diff、测试输出和提交；
- 不得事后虚构暂停点或红灯记录。

## 建议任务

优先选择 `PLAN.md` 中范围独立、不会接触真实凭据和生产环境的任务，例如 Trace 脱敏规则测试或 Coding CLI 的纯离线参数验证。不得选择需要 API Key、服务器权限或课程方确认的任务。
