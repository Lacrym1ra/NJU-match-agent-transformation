# 南得一见 (NJU Match) 更新计划

以下是即将到来的功能迭代与版本规划：

## 校友（毕业生）全面适配预告
- **身份标识**：个人档案阶段新增「毕业生」选项
- **动态问卷**：针对校友，「未来倾向发展的省份」将自动转化为「目前所在/工作省份」
- **偏好选择**：匹配偏好的年级新增「毕业生」选项，可自由选择期望范围
- **异地接受度**：题目动态调整，在校生为「跨校区」，已毕业身份将转化为「不同工作城市或异地」等

## 圈子社交与模块化名片预告
- **全新极简组件**：全新的模块化名片系统，结构分离为基础信息、社交通讯录、兴趣爱好等碎片的自由组合，并支持独立配置隐私级别
- **自动特征提取**：组队频道将动态展示基于问卷提炼出的核心圈子标签（如通过游戏段位自动筛选排位搭子）
- **五重隐私保护架构**：从列表展示、公开名片、添加好友、到完整名片与解密联系方式，层层递进防止站内直球骚扰
- **圈子千人千面体验**：引入独立的圈前数据动态覆写功能（Overrides），让你在特定版块自由隐藏或单独外显战绩资料
- **二次解密门槛**：包含微信等极度敏感通讯数据全局默认锁定，必须通过独占解锁申请通道经目标用户允许后方可解密展示

## 沉浸式论坛分级架构预告
- **全新论坛体系**：规划落地，划分全员可参与的全站大厅以及高浓度的小众圈子内部独占论坛
- **反水军墙**：优化社区纯净度，对于常规发布讨论帖强制校验身份（需注册满 7 天或系统认证过深度问卷）
- **加急组队帖**：新增特定类型，突破发帖资历时间限制，随时随刻都能呼唤即时搭子
