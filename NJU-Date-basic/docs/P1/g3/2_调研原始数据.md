# 用户调研原始数据（论坛与治理模块）

## 一、问卷统计结果（共 21 份）

> 注：以下数据提取自《校园全场景社交与交友匹配》需求调研问卷，并结合团队人工整理与可行性校准，重点关注论坛与社区治理相关问题。

- **Q1. 你平时在校园社区/论坛中最常进行的活动是什么？**
  - 浏览吃瓜、默默潜水不发言：占比最高，约 45%。
  - 寻找实用信息：约 30%。
  - 主动发帖求助或分享：占比较低，说明发帖门槛和心理压力需要被重点降低。

- **Q2. 阻碍你在现有校园平台上发帖或评论的最大原因是什么？**
  - 担心被认出真实身份，缺乏隐私保护：超过 50%。
  - 社区氛围不好、容易被杠或被攻击：约 25%。
  - 担心发帖内容写到一半丢失、编辑成本高：少量用户在开放题和访谈中补充提出。

- **Q3. 对于校园论坛的板块划分，你更倾向于哪种内容组织形式？**
  - 大板块分类 + 内部细分标签：约 70%。
  - 单纯按时间流展示：接受度较低，但仍希望保留“最新”入口。

- **Q4. 在互动体验方面，你认为哪些功能是校园论坛的“刚需”？**
  - 匿名发帖或匿名回复机制：最高票。
  - 帖子点赞、收藏、评论与楼中楼回复：基础刚需。
  - 评论点赞、优质评论置顶：多位受访者认为可以帮助快速看到重点讨论。
  - 帖内投票：适合二选一求建议、活动意向收集、轻量表态等场景。
  - 发帖草稿保存：不是最高频需求，但对长帖、求助帖和编辑中断场景具有明确价值。

- **Q5. 关于平台内的个人身份展示，你最期望的模式是？**
  - 前台匿名，后台实名，可按帖子切换身份：超过 70% 用户选择。

- **Q6. 你是否需要“推荐/最新/热门”等不同信息流排序方式？**
  - 多数用户希望默认推荐或热门，但同时保留最新排序，避免错过实时信息。

- **Q7. 对帖子卡片展示“摘要和封面图”，你认为是否能提升浏览效率？**
  - 多数用户认为摘要能帮助判断帖子是否值得点开。
  - 对封面图的接受度取决于内容类型，活动、失物招领、校园生活类帖子更需要封面。

- **Q8. 如果你在平台上遇到令人不适的内容，你通常会怎么做？**
  - 直接拉黑/屏蔽或顺手举报：两者比例接近，说明风控工具必须前置且操作成本要低。

- **Q9. 如果你提交了举报，你对平台的反馈机制有什么期望？**
  - 必须有站内信或系统消息明确告知处理结果：超过 60%。

- **Q10. 平台如果设立“信用分”或“阳光值”机制，你的态度是？**
  - 勉强接受，但前提是扣分标准公开透明，有申诉渠道。

## 二、开放性问题精选（痛点提取）

- **痛点 1（隐私与发声）**：“想要完全无压力的吐槽空间，熟人太多不敢发帖，一定要能随时切匿名。”
- **痛点 2（浏览效率）**：“现在很多帖子标题党，点进去才发现没用，希望列表里能看到一点摘要，最好能按热度或者推荐看。”
- **痛点 3（互动表达）**：“有些问题不一定要长篇评论，投票会更方便，比如选课、活动、要不要拼车这种。”
- **痛点 4（讨论秩序）**：“恶意评论要能举报，但也希望楼主能把真正有用的回复顶上去，不然大家后面看不到重点。”
- **痛点 5（反馈机制）**：“每次举报违规广告都是石沉大海，希望官方能有反馈，不然觉得举报也没用。”

## 三、访谈笔记摘要（共 8 人次）

- **访谈对象 A（大一，理工科）**：主要浏览校园信息，不常发帖。认为匿名机制是发帖前提，同时希望首页能优先看到高质量内容，而不是完全按时间倒序。
- **访谈对象 B（大二，文科）**：经常收藏有用帖子，希望收藏入口稳定；对帖子摘要有强需求，因为不想反复点开无关内容。
- **访谈对象 C（大二，理工科）**：认为投票适合轻量决策，比评论区刷屏更高效；希望投票结果能在帖子内直接查看。
- **访谈对象 D（大三，社团负责人）**：经常发布活动通知，认为封面图可以提升活动贴辨识度，草稿功能能避免编辑长帖时内容丢失。
- **访谈对象 E（大三，理工科）**：更关注治理反馈。曾举报广告但没有结果通知，因此希望举报后能收到处理状态。
- **访谈对象 F（大四，文科）**：认为评论区需要秩序，但不赞成随意“折叠”异见评论；更接受楼主置顶高价值评论和管理员处理违规内容。
- **访谈对象 G（研究生）**：担心匿名导致攻击性增强，支持“前台匿名、后台实名”和阳光值机制，但要求规则透明。
- **访谈对象 H（大一，交叉学科）**：希望论坛可以同时保留“最新”和“热门/推荐”，不同场景下切换浏览。

## 四、由调研推导出的论坛功能方向

1. **内容发布**：支持图文发帖、匿名/私密发帖、摘要与封面图、发帖草稿箱。
2. **内容发现**：支持推荐、最新、热门信息流，支持搜索与筛选。
3. **互动表达**：支持点赞、收藏、评论、楼中楼、评论点赞、帖内投票。
4. **讨论沉淀**：支持楼主置顶一级评论，管理员置顶帖子。
5. **社区治理**：支持举报闭环、阳光值治理、黑名单/屏蔽与后台违规处理。
