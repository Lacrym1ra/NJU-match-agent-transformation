## 二、运行方式

先启动只含数据库的 G2 demo 服务（`down -v` 保证重新执行 `init.sql`）：

```bash
docker compose -f docker-compose.g2-demo.yml down -v
docker compose -f docker-compose.g2-demo.yml up -d postgres
```

后端 DB 集成测试：

```bash
DATABASE_URL=postgres://postgres:postgres@127.0.0.1:55432/nju_date \
DB_SSL=false JWT_SECRET=nju-date-g2-test-jwt-secret ADMIN_KEY=nju-date-admin-test \
CONTACT_ENCRYPTION_KEY=nju-date-local-contact-encryption-key \
CONTACT_BLIND_INDEX_KEY=nju-date-local-contact-blind-index-key \
npm --prefix backend run test:g2:integration
```

前端真实后端集成测试（自动拉起 backend `3100` / frontend `3101`，`VITE_USE_MOCK=false`）：

```bash
# 同上环境变量
npm --prefix frontend run test:g2:integration
```

## 三、后端 DB 集成清单（`backend/tests/db/` · 19 用例）

### `friendContactService.test.ts`（10）—— 好友与联系方式全链路
- 发送好友申请 + 接受 → 同时建立圈内与全局好友关系
- 拒绝与重复 pending 申请 → 持久状态正确更新
- 删除单圈好友 → 同时回收孤立的全局好友关系
- `deleteAllFriends` → 原子删除好友关系与联系方式解锁记录
- 联系方式解锁通过 → 授权并展示圈内联系方式值
- 联系方式解锁拒绝 → 不泄露联系方式
- **并发**：双向并发好友申请只留 1 条 pending；并发接受同一申请只成功 1 次；并发审批联系方式只生效 1 次
- 非好友不能申请联系方式解锁

### `teamService.test.ts`（4）—— 组队生命周期
- 创建组队 → 生成组队、队长成员与加密联系方式 payload
- 直接加入至满员 → 溢出进候补 → 退出后候补自动补位
- 队长不能直接退队
- `getTeamupContacts` 拒绝非成员

### `chatService.test.ts`（5）—— 圈内聊天
- 发送消息 → 另一圈成员可拉取到该消息
- 重复 `clientMessageId` 幂等（不产生重复消息）
- 非成员不能发送或拉取圈聊天历史
- 删除自己的消息 → 历史中隐藏内容
- 已读状态 upsert → 返回未读数

## 五、按验收口径的覆盖对照

P4 要求：**≥1 个完整正常流程 + ≥2 个异常流程**。G2 实际覆盖如下。

### 完整正常流程（≥1，实际 3 条）
1. **好友→联系方式全链路**：发申请 → 接受 → 建立圈内+全局好友 → 申请联系方式解锁 → 审批通过 → 展示真实联系方式（`friendContactService.test.ts`）。
2. **组队全链路**：创建组队 → 直接加入至满员 → 溢出候补 → 成员退出后候补补位（`teamService.test.ts`）。
3. **圈内聊天链路**：发消息 → 另一成员可见 → 已读状态与未读数（`chatService.test.ts`）。
4. **前端真实后端 E2E**：登录 → 圈子发现 → 名片/好友/联系方式 → 组队/LiveChat（`g2-integration.spec.ts`）。

### 异常流程（≥2，实际多条）
1. **未登录访问拦截**：未登录访问 `/circles` 跳转登录（`g2-integration.spec.ts`）。
2. **越权访问**：非成员不能收发圈聊天、非好友不能申请联系方式、`getTeamupContacts` 拒绝非成员、队长不能直接退队（`chatService` / `friendContactService` / `teamService`）。
3. **并发竞态**：双向并发好友申请只留 1 条 pending、并发接受只成功 1 次、并发审批只生效 1 次（`friendContactService.test.ts`）。
4. **幂等与拒绝语义**：重复 `clientMessageId` 幂等、联系方式解锁拒绝不泄露（`chatService` / `friendContactService`）。
