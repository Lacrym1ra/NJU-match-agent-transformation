## 四、按验收口径的覆盖对照

| 验收口径 | 代表性用例 |
|---|---|
| 边界条件 | 聊天空/超长消息、入圈冷却 30 天窗口与重试边界、学号格式、入圈容量归一化 |
| 异常输入 | 组队非法 payload、入圈表单校验、联系方式字段约束、名片空字段过滤 |
| 权限校验 | 好友处理仅接收方可操作、广播仅发允许成员、组队结束后举报门控、仅站内安全跳转、同圈且活跃才能申请好友 |
| 状态转换 | 好友 pending→accept/reject、已处理不可重复、Heartbox 24h 门控、并发条件更新 |
| 关键业务规则与安全 | 联系方式加密/解密/脱敏/防篡改、敏感联系方式检测与聊天拦截、入圈反骚扰冷却 |
