## 五、API 测试代码结构

本轮 API 冒烟采用 Node 脚本直接调用本地服务，核心结构如下：

```javascript
const BASE = 'http://localhost:3000/api/v1';

async function req(label, method, path, body, token, opts = {}) {
  const headers = { 'Content-Type': 'application/json' };
  if (token) headers.Authorization = `Bearer ${token}`;
  if (opts.admin) headers['X-Admin-Key'] = ADMIN_KEY;

  const res = await fetch(`${BASE}${path}`, {
    method,
    headers,
    body: body == null ? undefined : JSON.stringify(body),
  });

  const data = await res.json().catch(() => ({}));
  const ok = opts.expect ? opts.expect(res.status, data) : res.ok;
  results.push({ label, method, path, status: res.status, ok });
  if (!ok) throw new Error(`${label} returned ${res.status}`);
  return data;
}
```

该脚本覆盖发帖、搜索、详情、点赞、收藏、评论、回复、评论点赞、私密权限、举报和管理员审核等主链路。
