## 一、本阶段 Sprint 边界说明

第一组（g1）的产品主线是：

```
注册 → 建档 → 问卷 → 主匹配 → 揭晓 → 历史 → 互动反馈
```

P4 阶段（第 10–14 周）的核心目标：
1. P0 功能全部可用且已前后端联调通过；
2. P1 功能基本可用（后端就绪，部分前台页面可随后续迭代补齐）；
3. 核心模块单元测试覆盖率 ≥ 60%；
4. 完成 AI 代码信任度实验与 AI 调试对决；
5. 整理 Bug 修复日志，确保可演示版本稳定。
